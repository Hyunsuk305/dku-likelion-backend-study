## **멤버 변수와 메서드**
- 멤버 변수는 객체의 데이터 저장
- 메서드는 객체의 기능 정의

## **상속**
- 부모 클래스 기능을 자식이 물려받음
- extends 뒤에는 하나의 클래스만 상속 가능

## **Getter/Setter**
- private 접근제어자로 외부 접근을 제한하면 Getter/Setter로 접근

## **오버라이딩/오버로딩**
- 오버로딩은 메서드 매개변수 다르게 정의
- 오버라이딩은 부모 클래스의 상속받은 메서드의 내용 변경

## **인터페이스**
- interface는 메서드 이름, 파라미터, 반환, 타입만 가질 수 있음
- 인스턴스 생성도 불가
- 기능의 표준화 위한 도구
- withdraw처럼 재정의할 때는 반드시 접근제어자 붙여야 함

## **예외 처리**
- ArithmeticException은 어떤 수를 0으로 나누는 것 같이 비정상 계산 중 발생
- IndexOutOfBoundsException은 인덱스 값이 범위를 넘어갈 경우 발생
- IllegalArgumentException은 메서드의 전달 인자 값이 잘못될 경우 발생
- exception은 예외 상황을 의미하는 모든 클래스의 가장 최상위 클래스
